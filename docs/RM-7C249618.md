# Minicore 라이브러리 목록

새 라이브러리(커널이든 유저랜드든)를 만들 때마다 이 문서에 항목을
추가한다(설계자 지시, 2026-09-14 - CLAUDE.md 규칙에도 명시).

## 커널 측 (minicore/libs/*)

| 이름 | 경로 | 대상 | 용도 |
|---|---|---|---|
| libkenv | minicore/libs/libkenv | 커널 전용 | freestanding C/C++ 초기 런타임(표준 정수 타입, memcpy류, Spinlock/AtomicPtr, kernel::string, C++20 코루틴 지원, cxxabi) |
| libcpio | minicore/libs/libcpio | 커널/유저 공용(표준 C++ 내장 타입만 사용) | CPIO(New ASCII Format) 아카이브 파서 - initrd 읽기용(PL-FC38956C) |
| libkmm | minicore/libs/libkmm | 커널 전용(커널 API를 직접 참조) | Slab 할당자(SP-D7013B26, 코어별 더블 매거진+전역 디포) |
| libelf | minicore/libs/libelf | 커널/유저 공용(`MINICORE_LIBELF_KERNEL` 매크로로 컴파일 모드 구분, 기본값은 유저 영역용) | ELF64 파서 + 커널 전용 프로세스 로더(`loadIntoAddressSpace`) - PN-58501EAA |
| minicore_libs_x86_64 | minicore/libs/x86_64 | 커널 전용 | x86_64 아키텍처 종속 코드(ISR 저지대 스텁, 포트 I/O, 소프트웨어 컨텍스트 스위칭 어셈블리) |

| libuserlandtest | userland/tests/libuserlandtest | 테스트용 유저 런타임 라이브러리 - shared/static 양쪽으로 빌드 가능해야 함(동적 라이브러리 지원 검증용) | 예정 |

## 기록 규칙

- 새 라이브러리 디렉터리(`minicore/libs/<name>` 또는
  `userland/{apps,libs,tests}/<name>`)를 실제로 만들 때마다 이 표에
  행을 추가한다 - 계획 단계(아직 코드 없음)는 "상태" 칸에 "예정"으로
  남겨 두고, 실제로 만들어지면 "완료"로 바꾼다.
- "대상" 칸에는 커널 전용/유저 전용/공용(매크로 구분 여부 포함)을
  명시한다.
- 이 문서를 다른 문서에서 인용할 때는 이 문서의 추적 코드를 그대로
  쓴다.
