# Minicore 초기 QA 시나리오 — 부팅/커널 기본 동작

아직 소스 코드가 전혀 없는 상태(main 브랜치)라 아래 항목은 전부
**아직 검증 안 됨**이다. 구현이 진행되면서 실측 확인된 항목만
체크 표시로 옮긴다.

## 부팅

- [ ] `--kernel`/`--initrd` 옵션으로 QEMU에 이미지를 직접 전달해
      커널이 부팅된다.
- [ ] 시리얼 포트로 커널 로그가 정상 출력된다.
- [ ] multiboot2 경로로 부팅된다.
- [ ] PVH(QEMU) 경로로 부팅된다.
- [ ] BIOS 경로로 부팅된다.
- [ ] EFI(UEFI) 경로로 부팅된다.

## 커널 기본 동작

- [ ] 유저랜드 준비(첫 프로세스 기동)까지 성공한다.
- [ ] SMP 환경에서 여러 코어가 정상적으로 스케줄링된다.
- [ ] 인터럽트가 발생하면 올바른 커널 서비스로 라우팅된다.
- [ ] 프로세스 간 IPC 메시지가 의도한 커널 서비스로 전파된다.
- [ ] 페이지 폴트 기반 on-demand 맵핑이 동작한다.
- [ ] 4K 페이지가 조건에 따라 2M 페이지로 병합된다.
- [ ] procfs 루트가 마운트되어 조회 가능하다.

## 파일 시스템 레이아웃

- [ ] `/boot`, `/sys/live`, `/sys/etc`, `/sys/bin`, `/sys/dev`, `/sys/tmp`,
      `/apps`, `/run`, `/usr/{사용자명}/...`, `/home/{사용자명}` 경로가
      설계된 구조대로 마운트/노출된다.
- [ ] `/home/{사용자명}`이 `/usr/{사용자명}/home`으로 올바르게
      리라이트되어 조회된다.
