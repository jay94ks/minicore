# 실행 계획: SMP AP(나머지 코어) 기동

ACPI MADT로 코어 목록/APIC ID 확보(완료), LAPIC 초기화(완료)까지는
끝났다. 이 계획은 실제로 BSP 말고 나머지 코어(AP)를 깨워 커널 코드를
실행시키는 부분이다.

## 선행 조건

- Acpi::cpuCount()/cpuApicId() (완료)
- Lapic (완료, ICR 레지스터 read/write는 추가 필요)
- PageFrameAllocator (완료 - AP별 스택 할당에 씀)

## 단계

0. **[완료, 2026-09-14] 최소 스핀락/원자 연산 프리미티브**
   (QU-B97FDA44): `minicore/libs/libkenv/spinlock.h`에 `Spinlock`
   (TAS 기반) + `SpinlockGuard`(RAII) + `AtomicU32` 구현. `Serial::write`
   전체와 `PageFrameAllocator`의 노드별 free list 조작
   (`allocOrderOnNode`/`freeOrder`)에 실제로 걸어 뒀다 - 지금은
   코어가 하나뿐이라 동작 차이는 없음(실측 - free_pages 등 수치가
   락 적용 전후로 동일). AP가 실제로 뜨는 다음 단계부터 의미가 생긴다.
   아직 안 잠근 공유 상태(Acpi의 정적 배열들, Lapic의
   gLapicVirtAddr 등)는 전부 "초기화 이후 읽기 전용"이라 지금은
   괜찮지만, AP 기동 코드를 짤 때 다시 한 번 훑어야 한다.
1. **16비트 실모드 트램폴린 작성**: 별도 `.S` 파일 - AP가
   INIT-SIPI를 받으면 vector*0x1000 물리주소(예: 0x8000)에서 16비트
   실모드로 시작한다. 여기서: GDT32 적재(BSP 것 재사용 가능하도록
   저지대에 배치되어 있어야 함) → CR0.PE 세팅 → 32비트 보호모드
   진입 → 기존 `common_32bit_entry`(멀티boot2 계획에서 뽑을 공용
   루틴)로 합류 → long mode → higher-half.
2. **트램폴린 배치**: 링커 스크립트에 낮은 고정 물리주소(1MB 이내,
   페이지 정렬) 섹션을 추가하거나, 부팅 시 PageFrameAllocator로
   받은 저지대 프레임에 트램폴린 코드를 복사(memcpy, libkenv)한다.
3. **AP별 자원 준비**: 코어마다 스택(PageFrameAllocator::allocOrder로
   충분한 크기 확보) + "이 AP가 몇 번째 코어인지/이 스택을 쓰라"는
   정보를 트램폴린이 읽을 수 있는 고정 위치에 기록.
4. **Lapic에 ICR(Interrupt Command Register, 0x300/0x310) read/write
   추가**: INIT-SIPI-SIPI 시퀀스 전송용. x2APIC PL과 겹치는 부분이니
   그 계획과 인터페이스를 맞춰 설계(추상화해 두면 이후 x2APIC 전환이
   쉬움).
5. **BSP의 기동 시퀀스**: 각 AP apic id에 대해 INIT(어서트→디어서트,
   딜레이) → SIPI(트램폴린 벡터) → 필요시 SIPI 재전송(구식 CPU
   대응) → 해당 AP가 "기동됨" 플래그를 세울 때까지 타임아웃 대기
   (Timer 활용).
6. **동기화**: 0단계에서 만든 원자적 카운터(또는 코어별 플래그
   배열)로 "몇 개 AP가 떴는지" 추적.
7. **AP 진입 후**: 자기 LAPIC 초기화(Lapic::init 재사용 가능한지
   검토 - PIC 마스크는 BSP가 이미 했으니 중복 방지 필요), IDT는
   전역(gIdt)이라 lidt만 다시 실행, 이후 idle(hlt 루프 - 스케줄러
   생기기 전까지는 할 일 없음).
8. **검증**: QA-26450C3E의 "SMP 환경에서 여러 코어가 스케줄링된다"는
   스케줄러가 있어야 완성되지만, 이 계획 자체의 검증은 "AP가 실제로
   깨어나 시리얼에 자기 APIC ID를 한 번 찍고 idle에 들어간다"로
   한정한다 - QEMU를 `-smp N`으로 띄워 N-1개의 "AP N 기동" 로그가
   찍히는지 확인.

## 미결 사항

- 트램폴린용 고정 물리주소를 링커 스크립트 정적 예약으로 할지,
  부팅 시 동적 할당으로 할지.
